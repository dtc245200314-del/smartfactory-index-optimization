# Nhật ký AI

Người dùng yêu cầu hoàn thành khóa học. Codex đọc yêu cầu SmartFactory, chọn index hai cột theo mẫu equality/range, tạo fixture độc lập và chạy MySQL thực để lấy EXPLAIN cùng thống kê storage. Đây là mô tả công việc thực tế; không dựng một cuộc hội thoại của học viên hay giả số liệu production.

Các điểm đã kiểm tra: chi phí covering index; secondary index chứa primary key; phân biệt Using index và Using index condition; storage cấp phát khác dung lượng file vật lý; mức cải thiện cần đo thay vì lấy tỷ lệ minh họa trong đề làm kết quả.
